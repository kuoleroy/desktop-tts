# Desktop TTS 桌面朗读助手

一个 Windows 桌面悬浮窗朗读工具：在任意软件中选中文字（双击 / Ctrl+A / 拖选），自动弹出朗读面板，选择音色与语速后即可朗读，也可一键导出 MP3。

- 音色由 **edge-tts**（微软 Edge 在线朗读接口）提供，免费、无需 Key、秒级出音频
- 服务内嵌在程序进程内，无需单独启动任何后台服务
- 本地 CosyVoice 模型作为断网兜底（可选）

## 功能特性

- **三种触发方式**：双击、Ctrl+A 全选、拖选（≥8px 自动识别）
- **防抖识别**：选中后 0.8s 防抖，期间快速重新选中会自动重置，避免误触
- **朗读面板**：6 种在线真人神经音色（edge）+ 2 种 Windows 本地语音（离线），语速 0.5~2.0、语调 ±15Hz
- **断网/接口失效自动兜底**：在线音色失败自动切换本机语音，无需手动操作
- **朗读按钮对准鼠标**：面板弹出时「朗读」按钮中心正对鼠标落点，无需移动鼠标即可点选
- **朗读范围过滤**：按软件（进程）白名单/黑名单，面板一键「此软件」添加当前软件
- **导出 MP3**：当前文本按所选音色/语速/语调合成并导出为 MP3 文件
- **磁盘缓存**：相同文本+参数只合成一次，重复朗读毫秒级返回；可设缓存上限自动清理
- **系统托盘**：可最小化到任务栏（托盘图标）
- **快捷键**：ESC 收起面板
- **配置记忆**：音色/语速/语调/过滤规则自动保存，重启沿用

## 环境要求

- Windows 10/11
- Python 3.10+（已测试 3.10 / 3.13）
- 朗读需联网（edge-tts 在线接口）

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt pystray

# 2. 运行
python desktop_tts.py        # 前台（可 Ctrl+C 退出）
# 或双击 run.bat            # 后台静默运行
```

启动后屏幕右下角出现蓝色「读」小球，即可正常使用。

## 使用说明

### 触发朗读

| 操作 | 说明 |
| --- | --- |
| 双击 | 选中一个词/句后触发 |
| Ctrl+A | 全选当前文档触发 |
| 拖选 | 按住左键拖选，松开后触发 |

触发后等待约 1 秒（防抖+合成），面板弹出，**「朗读」按钮对准鼠标位置**，直接点击即可朗读。

### 面板按钮

`朗读 / 暂停 / 此软件 / 导出MP3 / 停止 / 收起`

- **此软件**：把当前触发朗读的软件加入朗读范围（配合右键菜单的「朗读范围」使用）
- **导出MP3**：按当前音色/语速/语调合成当前文本并保存为 MP3
- **收起**：面板收回为小球（正在朗读的内容不受影响，可继续听完）

### 右键菜单（在小球或面板上右键）

- **收起** / **最小化到任务栏**（托盘图标，双击恢复）
- **缓存上限**：100MB / 300MB / 500MB / 1GB / 不限制，超限自动清理最旧音频；可打开缓存文件夹
- **朗读范围**：
  - 全部软件（默认）
  - 仅以下软件（白名单）
  - 排除以下软件（黑名单）
  - 管理列表：添加当前软件 / 删除选中
- **禁止识别**：临时关闭选词识别（防止干扰）
- **退出**：退出程序

### 快捷键

- **ESC**：收起面板（不停止朗读）

## 配置文件

### voices.json（音色配置）

音色、语速、语调列表集中在此文件，修改后重启生效：

```json
{
  "voices": {
    "yunJian": {
      "name": "云健·男",                       // 界面显示名
      "desc": "成年男声（edge 在线）",          // 说明（仅注释作用）
      "edge": "zh-CN-YunjianNeural"            // edge-tts 音色 ID（在线 API 参数）
    }
  },
  "speed_list": ["0.5", "0.7", "1.0", "2.0"],
  "pitch_list": ["-15Hz", "-5Hz", "+0Hz", "+10Hz", "+15Hz"],
  "edge_max_single": 2000                       // edge 单次合成最大字数
}
```

添加新音色：往 `voices` 里加一项即可，界面自动出现。文件缺失或格式错误时自动回退内置默认。

#### 本地语音（离线兜底）

`voices` 下的在线音色走 edge 在线接口；`sapi_voices` 下的本地音色（晓晓·本地、云希·本地）走 Windows 自带语音（System.Speech）：

- **Windows 11**：自带高质量神经语音（Microsoft Xiaoxiao / Yunxi Natural），音质接近在线音色
- **Windows 10**：一般只有传统语音（Huihui Desktop 等），音质一般，但**完全离线**
- 配置的本地语音在本机不存在时，会自动回退到任意可用的中文语音；一个中文语音都没有时返回失败
- 在线音色合成失败（断网/接口变更）时，也自动用本机语音兜底，无需手动切换

### config.json（运行配置，自动生成）

位于 `%APPDATA%\desktop-tts\config.json`，记录音色/语速/语调/缓存上限/朗读范围，程序自动读写，一般无需手工编辑。

## 架构说明

```
desktop_tts.py     桌面端主程序（UI、选词识别、防抖、播放）
server_core.py     内嵌合成服务（fastapi + edge-tts + 缓存 + CosyVoice 兜底）
edge_proc.py       edge-tts 子进程（保证合成不阻塞）
voices.json        音色/语速/语调配置
```

- 程序启动时在**进程内**拉起 8848 端口服务（无需手动启动）
- 朗读请求 → edge-tts 在线合成（mp3，约 1.5 秒）→ 磁盘缓存 → pygame 播放
- 相同文本+参数直接命中缓存，毫秒级返回
- 断网或 edge 失败时，如本机装有 CosyVoice（参考音频在 `server_core.py` 顶部 `REF_AUDIO` 配置）则回退本地合成；否则返回失败

### 缓存

- 位置：程序目录下 `cache\`（跟随程序所在位置，不占系统盘）
- 清理：按「缓存上限」设置自动删除最旧文件，也可手动删除

## 日志

- 运行日志：`%TEMP%\desktop_tts.log`（触发、读取、弹窗位置、服务状态等）

## 常见问题

**Q: 选中文字没有反应？**
确认未勾选右键菜单「禁止识别」；检查「朗读范围」是否限制了当前软件；查看日志 `%TEMP%\desktop_tts.log` 定位。

**Q: 朗读失败 / 合成慢？**
edge-tts 为在线接口，请确认网络正常。超长文本（>2000 字/块）会自动分块。

**Q: 端口 8848 被占用？**
服务只在本机回环地址监听，若被其他程序占用，先退出占用程序或重启本程序。
